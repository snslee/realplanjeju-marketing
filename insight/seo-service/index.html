SEO(검색엔진최적화) 대행은 무엇을 맡기는 일인가요?

2026년 9월 15일 기준 · 리얼플랜제주 온라인마케팅 팀

답부터
  1. SEO는 홈페이지를 고치는 일입니다 — 글을 더 쓰는 블로그 대행과도, 돈을 태우는 광고 대행과도 다릅니다.
  2. 순위를 약속하는 제안서는 거르십시오. 순위는 검색엔진이 정하고 대행사가 정하지 않습니다.
  3. 성과는 순위 한 줄이 아니라 색인 → 노출 → 클릭 → 문의 네 줄로 봅니다.

SEO 대행은 실제로 무엇을 하나요?

검색엔진이 페이지를 찾고, 읽고, 보여주게 만드는 일입니다. 크게 세 갈래 — 기술(찾고 읽게), 콘텐츠(무엇을 답하게), 신뢰(누가 쓴 글인지) — 로 나뉘고 셋이 다 있어야 움직입니다.

갈래하는 일확인하는 것
기술사이트맵·robots·색인 요청·속도·모바일검색엔진이 우리 페이지를 알고 있는가
구조제목·설명·제목 단계·내부 링크·구조화 데이터페이지가 무엇을 답하는지 기계가 아는가
콘텐츠질문에 답하는 문단, 표, 출처사람이 읽고 답을 얻는가
신뢰회사 신원, 등록번호, 실적, 갱신일누가 쓴 글인지 드러나는가

셋 중 하나만 하면 결과가 안 납니다. 글만 쌓으면 색인이 안 되고, 기술만 고치면 답할 내용이 없습니다.

광고 대행·블로그 대행과 어떻게 다른가요?

돈을 쓰는 곳과 남는 것이 다릅니다. 광고는 멈추면 노출이 즉시 사라지고, 블로그는 글이 쌓이며, SEO는 홈페이지 자체가 자산이 됩니다. 셋은 경쟁 관계가 아니라 역할이 다릅니다.

구분광고 대행블로그 대행SEO 대행
손대는 곳광고 계정외부 블로그우리 홈페이지
멈추면노출 즉시 사라짐글은 남음페이지는 남음
효과 시점당일수 주수 주~수 개월
비용 구조광고비+수수료월 운영비월 작업비
남는 자산데이터글사이트 구조와 문서

지금 문의가 급하면 광고, 꾸준히 쌓으려면 SEO입니다. 둘을 같은 자로 재면 판단이 흐려집니다.

「검색 1위 보장」이라는 제안은 믿어도 되나요?

검색 순위는 검색엔진이 정하는 것이라 제3자가 보장할 수 있는 대상이 아닙니다. 보장이라는 표현이 제안서에 있으면 어떤 근거로 적었는지, 달성하지 못하면 어떻게 되는지를 문장으로 받아 두십시오.

  • 「무조건」·「100%」·「영구」 같은 최상급 표현의 근거를 요구합니다
  • 달성 실패 시 환불 또는 연장 조건이 계약서에 있는지 봅니다
  • 순위를 만드는 방법이 검색엔진 정책에 어긋나지 않는지 확인합니다
  • 외부에서 링크를 사 오는 방식인지 작업 내역으로 확인합니다
  • 공정거래위원회 표시·광고 기준에 비춰 근거 없는 최상급이 아닌지 봅니다
검색 순위는 검색엔진이 정합니다. 그래서 순위를 약속하지 않고, 바꿀 수 있는 것 — 페이지 구조, 제목과 설명, 내부 링크, 색인 제출, 갱신 주기 — 만 계약서에 적습니다. 측정은 순위 하나가 아니라 색인·노출·클릭·문의 네 줄로 봅니다.리얼플랜제주 마케팅 운영 기준 (2026-09-15)

계약서에는 무엇이 적혀 있어야 하나요?

작업 범위와 산출물이 수량으로 적혀야 합니다. SEO는 겉으로 눈에 띄지 않는 작업이 많아서, 무엇을 몇 건 했는지가 계약서에 적혀 있지 않으면 한 달 뒤에 무엇을 받았는지를 놓고 다투게 됩니다.

조항적혀 있어야 할 것비어 있으면
작업 범위기술·구조·콘텐츠 중 무엇을 하는지글만 쓰고 끝납니다
월 산출물페이지 수·수정 건수·보고서무엇을 받았는지 모릅니다
접근 권한서버·CMS·검색 콘솔 권한 범위계약 종료 후 자료가 안 남습니다
소유권제작 문서와 원본 파일다시 만들어야 합니다
중도 해지통보 시점과 정산분쟁이 됩니다

검색 콘솔 권한은 광고주 계정으로 만들고 대행사에 권한을 부여하는 방식이 안전합니다.

성과는 어떻게 재나요?

네 줄을 순서대로 봅니다. 색인된 페이지 수 → 검색 노출 수 → 클릭 수 → 문의 건수입니다. 앞 줄이 안 움직이면 뒤 줄은 움직이지 않으므로, 어디서 막혔는지가 바로 보입니다.

순서보는 숫자안 움직이면
1색인된 페이지 수기술 문제 — 사이트맵·색인 요청부터
2검색 노출 수주제가 검색되는 말과 어긋남
3클릭 수제목과 설명이 안 읽힘
4문의 건수페이지에 다음 행동이 없음

한국에서는 네이버와 구글을 나눠 봅니다. 색인 방식과 노출 자리가 서로 달라 한 표에 합치면 오판합니다.
